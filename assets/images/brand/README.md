# ブランド画像

ブランド画像の用途とファイル名を管理する場所です。

## 現在使用している画像

| ファイル | サイズ | 主な使用場所 | 状態 |
| --- | --- | --- | --- |
| `../panda-lab.png` | 1254×1254 | ヘッダー、ホーム、プロフィール | 使用中 |

`panda-lab.png` は既存ページから参照されているため、現時点では移動・改名しません。

## 将来の分類

- `icons/`：Instagram、YouTube、メールなどにも使う正方形アイコン
- ロゴ：正式なロゴ画像が追加された時点で専用フォルダを作る
- 画像：用途ごとの画像は、権利と使用場所を記録してから追加する

画像を追加したら、内部のブランド管理資料にファイル名、サイズ、使用場所、使用開始日を記録します。
