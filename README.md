# 先生のちいさなアプリ実験室

小学校の教室や職員室で生まれた「あったらいいな」を、ちいさく試し、少しずつ育てていくサイトです。

## 公開ページ

- ホーム
- ちいラボアプリ
- ちいラボ教材
- ちいラボノート
- ちいラボエッセイ
- 実験室
- プロフィール

## ブランド情報

- サイト名：先生のちいさなアプリ実験室
- 運営者名：ちいラボ先生🐼
- キャッチコピー：教室から、ひとつずつ。

運営者名とサイト名を一続きで表示するときは、`ちいラボ先生🐼 先生のちいさなアプリ実験室` と表記します。

## 公開状態

現在は試作公開中です。ラップ教材の一部を短い紹介動画で掲載しています。自分人形の実践記事では、帽子なしの自分人形と空欄の縦書き吹き出しのPDFを掲載しています。外部フォーム、有料機能、広告、アフィリエイト等は実装していません。

## 公開対象外

内部の管理資料、確認用スクリーンショット、比較用試作、作業用原本、Word・Excel・PowerPoint・PDF・zip等は、この公開用リポジトリの管理対象から除外しています。

## 自分人形の配布用PDF

記事は `notes/self-doll/index.html`、配布用コピー2点は `assets/downloads/self-doll/` に置いています。

- `self-doll-no-hat.pdf`：帽子なし、A4・9人分、1体約5cm×8cm
- `speech-bubbles-blank.pdf`：空欄の縦書き吹き出し、A4・4枚

PDFの除外ルールは維持し、この2ファイル名だけを明示的に許可しています。赤帽子版、Word原本、確認資料、他のPDFは含めません。
フォントの出典とライセンスは同フォルダーの `FONT-CREDIT.txt` と `OFL.txt` に記載しています。
