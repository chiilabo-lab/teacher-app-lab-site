毎週の時間割に、
ほしい工夫を

週を切り替える工夫と、
手元の資料を生かす工夫。

毎週使っている時間割アプリ。5日表示と6日表示の切り替えや、行事・休日の表示など、毎週触るところを少しずつ整えています。

40秒の動画をYouTubeで見る →

本文作成：2026.10.05　最終見直し：2026.10.07

この記事は、毎週使っている元アプリの実践紹介です。

サイトで試せる版は「保存なし試験掲載版」です。データの保存・読込などを停止しています。掲載版で試せる機能を見る

以下の図は操作・資料活用の仕組みを伝えるイメージです。実際の操作画面ではありません。

01 / その週に合わせる

5日・6日、前週・次週。
使う週へ、切り替える。

5日表示と6日表示は、日数メニューで選びます。

行事や休日を表示するときは、日付と名前を入れてからボタンを押します。名前が空欄の場合は「休日」と表示されます。

前週・次週へは、ボタンで1週間ずつ移動できます。週を移動した後も、日付や行事は確認してから使います。

02 / 昨年度の資料を生かす

昨年度のデータを、
今年のたたき台に。

このアプリで保存した昨年度のJSONデータを読み込み、近い時期の週を、今年の時間割づくりのたたき台にできます。

日付や行事、授業の進み具合は今年に合わせて確認・調整します。以前の内容を生かしながら、その週に必要な形へ整えていく使い方です。AIが予定を予測する機能ではありません。

03 / 単元候補を使う

教育課程をもとにした
単元一覧も。

教育課程をもとに作った単元一覧を登録すると、教科や月に応じた単元候補を使えます。

対応している形式はJSON・CSV・TXTです。CSV・TXTは「月,教科名,単元名」の順で用意します。教育課程PDFの本文を解析する機能ではありません。

04 / 裏面も活用する

裏面には、
今ある資料も。

時間割の裏面には、文字を入力したり、画像やPDFを入れたりできます。昨年度のお知らせや自分で作った表など、手元の資料も生かせます。

PDFで表示できるのは1ページ目です。

05 / 使いながら育てる

使って気付いたことを、
ひとつずつ。

「ここを切り替えたい」「この資料も使いたい」。そうした気付きをCodexに伝え、形にして、確かめて、また使う。

使う → 気付く → 直す → また使う

毎週の仕事の中で、少しずつ育てています。
